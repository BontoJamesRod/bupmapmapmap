# Security & Privacy

## Privacy
BUP Navi collects **nothing**:
- No accounts, no tracking cookies, no analytics (v1).
- Your location is used only on your device to draw the "You are here" dot and start directions. It is never sent or stored.
- The only optional preference saved is your theme (light/dark), stored in your own browser.
- Map tiles are loaded from a third-party tile server, which sees standard request data (IP, map area) as with any website.

If this ever changes, it will be announced on the About page before it takes effect.

## Reporting a vulnerability
Please **don't open a public issue**. Use GitHub's *Report a vulnerability* (Security tab, "Advisories"), and we'll respond within 7 days.

In scope: XSS via campus data, CSP bypasses, supply-chain issues in dependencies, and anything that could leak a user's location.
